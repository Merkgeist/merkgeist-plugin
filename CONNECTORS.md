# Connectors

## How tool references work

The skills use `~~email` as a placeholder for whatever email tool you have connected. The plugin is
tool-agnostic: it describes the workflow, not a specific product.

## Connectors for this plugin

| Category | Placeholder | Options                                   |
| -------- | ----------- | ----------------------------------------- |
| Email    | `~~email`   | Gmail, Microsoft 365 / Outlook, any IMAP connector |

The plugin brings no connector of its own and no server. It only reads the mailbox you connect yourself.
